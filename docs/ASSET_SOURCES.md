## Network access

Claude Code cloud sessions can reach GitHub and package registries, but other sites may be blocked. Before M1, Josh should check whether the Claude Code environment can reach `polyhaven.com`, `dl.polyhaven.org`, `api.polyhaven.com` and `ambientcg.com`. If the environment has network settings, allow those domains. If not, Claude Code writes the exact list of files it needs into `docs/ASSET_REQUESTS.md`, with direct links, and Josh downloads them into `assets/incoming/` (a few minutes per batch).

## Poly Haven (CC0)

- **Models:** realistic furniture, kitchenware, tools, plants, rocks and props. Good fits for 1952: wooden chairs and tables, cabinets and dressers, armchairs, crates and barrels, enamel and tin kitchenware, oil lamps, buckets, garden tools, potted plants. Download the glTF version at **1k** textures for the web, and **2k** only for hero items on High quality.
- **HDRIs:** pick 4 or 5 country skies (clear morning, midday, overcast, sunset, night) for the sky and ambient light.
- **Textures:** extra wood, plaster and ground textures.
- Poly Haven has a public API (`api.polyhaven.com`) that lists assets and file URLs. Write `tools/assets/fetch_polyhaven.py` that downloads a curated list from `data/asset_manifest.json`.

## ambientCG (CC0)

PBR materials for everything procedural: painted timber, weatherboard, planks, plywood, fibro, plaster, wallpaper base papers, bricks, roof iron, terracotta tiles, ceramic tiles, linoleum, carpet, fabrics (cotton, wool, chenille-like), gravel, dirt, grass, mud, concrete. Download at 1k (JPG). Write `tools/assets/fetch_ambientcg.py`, driven by the same manifest.

**Paint and wallpaper:** use neutral base materials (smooth paint, textured paper) and tint them in the shader with the swatch colour, so one material gives the whole 1950s paint chart. Wallpaper patterns are separate tileable pattern textures (generated by Claude Code as SVG or PNG: florals, stripes, small prints) multiplied over the paper base.

## Custom 1950s props

Model these with Blender Python scripts (`pip install bpy` gives headless Blender in the cloud session), export glTF, and use ambientCG materials:

Wood stove with flue, enamel icebox, kerosene lamp, wireless set, radiogram (Chapter 2), telephone switchboard, wall telephone, cash tin and register, shop counter and shelving with tins, pressed metal ceiling panels, wash house copper and trough, rotary clothes line, corrugated iron water tank on a stand, dunny, chook pen, cast iron verandah lace, picket and paling fences, mill machinery, church pews, a hotel bar.

Each prop gets named material slots so the Design tool can recolour it (`docs/HOUSE_BUILDING.md`).

## Residents with MPFB (CC0)

MPFB (MakeHuman for Blender) generates realistic human bodies from sliders. The base mesh, targets and skins are CC0, so characters can ship in a closed-source game. The add-on code is GPL, which doesn't affect exported characters. Check the licence of any clothing assets used. Clothing not marked CC0 counts as third-party.

**Pipeline** (`tools/characters/`):
1. Install Blender headless with `pip install bpy` (if pip can't, ask Josh to run it locally) and the MPFB add-on.
2. For each resident in `data/residents.json`, set sliders from their age, build and features, and pick hair.
3. Add 1950s clothing: start from MPFB's CC0 clothes where available and modify them, or model simple garments (dresses, trousers, shirts, cardigans, aprons, jackets, hats) in Blender scripts.
4. Add facial blend shapes for neutral, happy, sad, angry, nervous and surprised.
5. Rig to a standard humanoid skeleton, retarget animations, decimate to the triangle budget (`docs/ART_DIRECTION.md`), and export glTF with LOD0 and LOD1.

**Where it stands (M5):** `bash tools/characters/setup_mpfb.sh` clones MPFB 2 from GitHub (its release page and the MakeHuman asset servers are blocked from the cloud session) and packages it as a Blender extension; `tools/characters/make_agnes.py` installs it into headless Blender and builds Agnes. No clothing packs are reachable, so her clothes are MPFB's own CC0 helper geometry: the tights helper (smoothed over the torso) is her cardigan and stockings, the skirt helper her skirt, and the body shows only at the head, neck, hands and feet. Material slots (skin, hair, top, bottom, legs, shoes) are split by bone and coloured in game by `ResidentLook`, like the placeholder mannequins. She's normalised to the mannequins' 1.76 m so one height scale works for everyone, decimated to 9,000 triangles (LOD0) and 2,800 (LOD1), and given the same idle, walk and sit animations, keyed as world-space swings so the A-pose rest doesn't matter. Still to do per `docs/BACKLOG.md`: shoes, hair meshes, facial shapes and the other residents.

**Character customisation:** because MPFB is slider-based, the same pipeline can later power an in-game "make a resident" screen for applicant families, with sliders baked into blend shapes.

## Optional paid packs

If more period furniture is needed, Unity Asset Store packs can be used in other engines (Unity's support page confirms this, as long as the raw files aren't redistributed). Fab packs need their licence checked. Only buy packs whose look matches Poly Haven's realism, and convert them to the project's material setup.

## Sound

Synthesised effects (`tools/audio/`) for UI, building and ambience, plus CC0 recordings from Freesound for realistic sounds (screen doors, kookaburras, magpies, rain on an iron roof, a wood stove crackling, a train at the siding). Music from Incompetech (CC BY, credit required) or Freesound (CC0).

## Optional 2D portraits (Gemini)

The game can render live 3D portraits of each resident, so Gemini portraits are optional. If wanted for menus or the case file, use this style block in a new Gemini chat for each character, then the character's description from `docs/RESIDENTS.md`:

```
A warm, semi-realistic character portrait, like key art for a modern life simulation game. Realistic proportions with gently idealised features, soft natural skin, soft window light from the upper right. Head and shoulders, 4:5, plain warm off-white background. 1950s country Australia clothing and hair. No text. An original person, not resembling any real or famous person or existing game character.
```

Turn off Gemini's visible watermark first (cog, then Media watermark). Disclose AI-made content that players see on Steam.

## Licence rules for anything else

Only CC0, CC BY, SIL OFL, Apache 2.0, MIT, public domain, or a paid licence that allows commercial games in any engine. Never "personal use only" assets, ripped game assets, or anything imitating a real brand or game.
